# 简谱键盘（JianpuKeyboard）

一个「简谱 → 键盘鼠标自动演奏」的 Windows 桌面程序：识别简谱文本，自动把音符转换为 8 键键盘（z x c v b n m ,）配合鼠标键的按法并注入系统，可挂后台运行，附带钢琴音、乐谱库和全局快捷键。

## 一、键盘键位映射

表格

| 键盘键 | 简谱音符 | 相对基准音高 |
| --- | --- | --- |
| Z | 1 | 基准（MIDI 60） |
| X | 2 | +2 半音 |
| C | 3 | +4 半音 |
| V | 4 | +5 半音 |
| B | 5 | +7 半音 |
| N | 6 | +9 半音 |
| M | 7 | +11 半音 |
| , | 1' | 高八度 do（+12 半音） |

音高计算公式：`基准 60 + 大调音阶偏移 + 八度 × 12 + 升降半音`。

特殊规则：1'（高八度 do）固定落在 `,` 键；更高八度（如 1''）为 `,` 键 + 鼠标右键叠加。

## 二、鼠标键自动识别

鼠标键由谱面自动判定，无需手动选择，可叠加：

表格

| 谱面情况 | 鼠标动作 |
| --- | --- |
| 高八度音（如 1' 2'） | 右键 |
| 低八度音（如 6. _6） | 左键 |
| 升 / 降半音（#4 b7） | 中键 |

叠加示例：`1''` = `,` 键 + 右键；`#6'` = n 键 + 右键 + 中键。每个音符先按鼠标键、再按键盘键，松开时逆序释放。

## 三、简谱文本语法

表格

| 符号 | 含义 |
| --- | --- |
| 1~7 | 音符。全角数字（１２３）自动转半角 |
| 0 | 休止符，占 1 拍，不按键不发声 |
| ' ^ * | 数字后 = 升八度（如 1'） |
| , | 数字后 = 降八度（如 1,） |
| # / b | 升 / 降半音，前后皆可（#4、4#、b7、7b） |
| . | 数字后且后跟数字 = 附点（+0.5 拍）；否则 = 低八度（如 6.） |
| · / • | 中间点 = 附点，可叠加：1・=1.5 拍、1・・=1.75 拍 |
| _ | 数字前 = 低八度（*6）；数字后 = 半拍（1*） |
| - | 数字后 = 延长 +1 拍；两音符之间 = 给前一个音符 +1 拍 |
| BPM n | 首行元数据，解析时忽略，仅用于记录速度 |
| 其他字符 | 空格、标点、歌词等一律跳过，不影响解析 |

时值规则：基础 1 拍；`_` 减为半拍；`-` 每次加 1 拍；`·` 附点按基础时值叠加（+0.5 → +0.25 → +0.125……）。

## 四、演奏

- 点击「▶ 开始演奏」立即开始，无倒计时。
- 每个音符的执行顺序：按鼠标键（如有）→ 按键盘键 → 保持（拍数 × 60/BPM 秒）→ 松开。
- 休止符：只等待，不按键。
- 速度 BPM：20~400，滑块与手动输入联动，可保存进乐谱。
- 静音（默认开启）：只注入按键、不播钢琴音，作用于手动点键、自动演奏、行预览三处。
- 钢琴音为程序内合成波形（基频 + 7 个泛音，自然衰减），非外部音频文件。
- 自动演奏中晃动鼠标、按其他键不影响注入。

## 五、乐谱库

- 乐谱保存在 exe 旁 `乐谱库\*.txt`。
- 窗口内可直接新建、下拉选择、保存、删除，无需手动找文件。
- 启动时自动打开乐谱库中的第一个乐谱。
- 保存乐谱时若当前 BPM 不是默认值，首行自动写入 `BPM n`，下次加载自动还原速度。

## 六、全局快捷键

- 默认组合：Ctrl+F1 开始 / Ctrl+F2 暂停 / Ctrl+F3 终止。
- 修饰键可选：Alt、Ctrl、Shift、Win，以及两两组合（Alt+Ctrl、Alt+Shift、Ctrl+Shift）。
- 按键可选：0-9、A-Z、F1-F12。
- 修改下拉框后立即自动保存到 exe 旁 `快捷键.json`，下次启动自动加载，无需重新设置；三组快捷键不可重复。
- 快捷键通过系统级键盘钩子实现，程序后台运行、全屏游戏中均可触发。
- 需要以管理员身份运行（UAC 点 "是"），才能对管理员权限运行的游戏注入按键。

## 七、行预览

- 每行简谱行首有「☐ 复选框 + ▶ 按钮」，所有行的按钮纵向对齐。
- ▶：试听单行，只发声、不注入键盘鼠标。
- ☑ 全选 / ☐ 取消全选：批量勾选。
- 「▶ 预览选中行」：将勾选的多行按顺序合并播放。
- 「■ 终止预览」：随时停止正在播放的预览。
- 预览按当前 BPM 播放；静音开启时预览不发声。

## 八、其他说明

- 窗口默认 900×800，内容超高时出现纵向滚动条。
- 程序适用于合法场景的模拟按键（游戏内自动演奏需注意对应游戏的反作弊规则与账号风险）。
